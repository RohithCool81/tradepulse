## Deploying on Replit

1. Create a new Repl
   - Choose "Import from GitHub"
   - Paste this repository's URL

2. The project will automatically install dependencies and start the development server

3. If you need to manually install dependencies:
   ```bash
   npm install
   ```

4. To run the development server:
   ```bash
   npm run dev
   ```

5. To build for production:
   ```bash
   npm run build
   npm start
   ```
